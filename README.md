## 📌 About the Project
**TaskFlow** is a robust task and project management application inspired by Trello. This project was developed to demonstrate skills in software architecture, communication between systems (REST API), and complex state management on the frontend.

This is a **Fullstack** project using **Go (Golang)** on the backend and **React + TypeScript** on the frontend, focusing on high performance and scalability.
Use the .env.example files provided to use your own enviroment variables
